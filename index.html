Projetos

1. Controle de Faturas de Cartão de Crédito

A aplicação foi criada para controlar compras realizadas por diferentes pessoas em um mesmo cartão, permitindo identificar os responsáveis, calcular valores a pagar e acompanhar faturas pendentes.

A ideia surgiu de um problema pessoal somado com a minha vontade de aprender sobre desenvolvimento web.
Repositório: Projeto Cartão de Crédito

2. Análise de times e ligas de futebol

E se uma pessoa pretende saber um pouco mais sobre times de ligas de futebol como estatísticas ou histórico de confrontos? Não é difícil de conseguir essas informações, mas para isso a pessoa deve acessar vários sites diferentes para consegui-las.
Este projeto visa concentrar essas informações em um só lugar com uma interface amigável, rica em detalhes e atualizada.

Ao carregar o site, clique na setinha no canto superior esquerdo.
Para acessar o site: Estatísticas de futebol
Repositório para mais informações: Rep. Estatísticas de futebol
